Standing invitation

The most valuable thing anyone can contribute here has not been built yet.

Seven evidence classes exist. The one wanted most is causal impact — baseline, counterfactual, independent measurement, attribution, stated uncertainty. Nobody has specified it. A class proposal is itself a claim: ship a reference verifier and a corpus of manifests built to pass wrongly, and it settles when the verifier rejects every one.
